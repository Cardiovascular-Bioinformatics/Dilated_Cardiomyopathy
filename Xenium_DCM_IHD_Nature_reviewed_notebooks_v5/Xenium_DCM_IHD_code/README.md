# Xenium spatial transcriptomics: DCM and IHD

Code supporting the Xenium cell-type annotation and spatial-proximity analyses for dilated cardiomyopathy (DCM) and ischaemic heart disease (IHD).

## Repository contents

| File | Purpose | Main output |
|---|---|---|
| `01_Xenium_cell_type_annotation_DCM_IHD.ipynb` | DCM annotation and initial IHD annotation | `DCM_final.h5ad`; `adata_IHD_annotated.h5ad`; DCM intermediate checkpoints |
| `02_IHD_compartment_refinement_to_v3.ipynb` | IHD fibroblast, cardiomyocyte, vascular and immune compartment refinement | `adata_celltype_corrected_v3.h5ad` |
| `03_IHD_final_fibroblast_refinement.ipynb` | Final IHD fibroblast refinement | `adata_celltype_final_corrected_v4.h5ad` |

## Cell labels and mixed-marker clusters

The annotation workflow uses `contaminated` as an operational quality-control label, not as a biological cell type. It captures clusters or cells with ambiguous or mixed lineage-marker patterns. These are reviewed by separate reclustering and marker inspection; cells are reassigned only when a coherent lineage signature supports it. A mixed-marker profile alone does not establish whether the cause is segmentation error, a doublet or genuine co-expression.

## Run order

Run the notebooks in order, from the same working directory and Python environment:

1. `01_Xenium_cell_type_annotation_DCM_IHD.ipynb`
2. `02_IHD_compartment_refinement_to_v3.ipynb`
3. `03_IHD_final_fibroblast_refinement.ipynb`
4. `04_Xenium_spatial_proximity_DCM_IHD.ipynb`

The DCM annotation uses the resolution-0.6 BANKSY clustering for the recorded manual mapping; resolutions 1.0, 1.2 and 0.8 are also evaluated as in the original analysis. IHD uses the 5th-percentile lower QC cutoff and 99.5th-percentile upper cutoff, whereas DCM uses a lower cutoff of 10 counts and 10 detected genes and a 99.5th-percentile upper cutoff. These are different choices in the original analysis and should be described in the manuscript rather than silently harmonized.

The IHD refinement saves `adata_global_fb_cm_cleaned_annotated.h5ad` before the vascular-refinement section reloads it. The final IHD annotation is written to `adata_celltype_final_corrected_v4.h5ad`.

## Analysis and statistical interpretation

Notebook 04 reports the supplied median-distance summaries separately from distances recalculated from the annotated `.h5ad` objects. The original HTML notebooks contain multiple spatial-analysis sections, including additional permutation, paired-test and spatial-regression analyses. This release intentionally does not include the additional permutation tests, paired Wilcoxon tests or spatial-regression analyses present in `IHD_Spatial_plot.html`; the current release focuses on the targeted nearest-anchor comparisons and broad ECM-marker screen described above. This omission is appropriate only if those additional analyses are not reported in the manuscript or supplement. If any are reported, their exact source methods must be restored here before submission. The random-control analysis reports the median of 100 one-sided Mann–Whitney U p-values (`alternative="less"`), as implemented in the notebook. Confirm that each reported statistic and figure corresponds to the exact code path included in the public repository.

Cell-level comparisons can be affected by within-sample dependence. If donor/section identifiers are available and inferential claims are based on multiple cells from the same specimen, use a sample-aware analysis or clearly state the limitation. The broad ECM screen's one-sided test is directional and should be justified in the Methods.
